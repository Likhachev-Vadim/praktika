# ImportMarket — модуль импорта каталога товаров

Учебное ASP.NET Core MVC-приложение для загрузки товарного каталога из CSV. После проверки корректные строки добавляются в коллекцию в памяти процесса. База данных и внешнее хранилище не используются.

## Возможности

- загрузка CSV в UTF-8, размер файла до 2 МБ;
- автоматическое распознавание разделителя `,` или `;`;
- поддержка кавычек в значениях и BOM;
- проверка обязательных столбцов `sku`, `name`, `price`, `stock`, `brand`, `warranty_months`;
- вариант «Электроника»: непустой бренд, целая гарантия от 0 до 60 месяцев и необязательный номер модели;
- проверка цены, количества, статуса активности и повторного артикула;
- поле `is_active` принимает `true`/`false` и `1`/`0`;
- вывод номера строки и текста ошибки;
- вывод загруженных товаров и агрегированных показателей каталога;
- защита POST-формы antiforgery-токеном.

## Запуск

Нужен .NET SDK 8.0 или новее.

```powershell
dotnet restore ProductCsvImporter.sln
dotnet run --project ProductCsvImporter/ProductCsvImporter.csproj
```

После запуска откройте локальный адрес, который выведет `dotnet run` (обычно `https://localhost:7xxx` или `http://localhost:5xxx`). Пример корректного файла находится в `ProductCsvImporter/wwwroot/sample-products.csv`.

В `ProductCsvImporter/wwwroot/examples` находятся CSV с пустым брендом и неверной гарантией, повтором SKU, неверной ценой и пустым содержимым.

## Проверка

```powershell
dotnet test ProductCsvImporter.sln
```

Набор из 12 тестовых случаев проверяет форматы CSV, обязательные заголовки, дубли SKU, цену, остаток, активность, обязательность бренда, диапазон гарантии и необязательный номер модели.

## Ограничения учебной версии

Коллекция очищается при перезапуске приложения, потому что задание предполагает хранение данных в памяти. Для промышленной эксплуатации потребовались бы постоянное хранилище, аудит операций, авторизация, лимиты/защита от вредоносных файлов и отдельный полноценный CSV-парсер для сложных многострочных значений.
## Материалы для отчёта

Папка `artifacts` содержит фактические снимки локального приложения: пустой каталог, форма импорта, результат успешной загрузки, заполненный каталог и ошибки валидации. Снимки сняты при демонстрационном запуске приложения и не являются изображениями реальной системы предприятия.
