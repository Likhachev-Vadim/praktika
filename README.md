# ImportMarket

Учебный проект по производственной практике ПП.02.01, вариант № 1 «Электроника». Приложение ASP.NET Core MVC загружает товарный каталог из CSV, проверяет обязательный бренд и гарантию от 0 до 60 месяцев и показывает результаты импорта. Номер модели может отсутствовать. Каталог хранится в памяти приложения.

## Запуск

Откройте `ProductCsvImporter.sln` в Visual Studio с поддержкой .NET 8. Выберите `ProductCsvImporter` как запускаемый проект и нажмите F5.

Для запуска из командной строки с .NET SDK 8:

```powershell
dotnet run --project ProductCsvImporter/ProductCsvImporter.csproj
```

Откройте адрес, который появится в консоли. Пример входных данных находится в `ProductCsvImporter/wwwroot/sample-products.csv`.

## Тесты

```powershell
dotnet test ProductCsvImporter.sln
```

В решении 12 тестовых случаев xUnit. Их также можно запустить через «Обозреватель тестов» в Visual Studio.
